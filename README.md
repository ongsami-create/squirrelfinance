# Squirrel Finance - 财务订单查询系统

> 给公司财务用的报价单查询/下载门户

## 这是什么

财务（不需要懂技术）能在一个页面上看到公司所有销售员的所有客户报价，按客户、日期、金额快速筛选，找到需要的报价单后**一键预览并导出 PDF / Excel**。

数据**实时同步**自 Squirrel Designer 报价系统 — 销售那边一报价，财务这边立刻能看到。

## 怎么用

### 打开系统

在浏览器打开：**https://ongsami-create.github.io/squirrelfinance/**

### 切换业务员

顶部一排 tab：PSD / JSD / FSD / TSD / VSD / TESD / SSD / ASD
- 点哪个 tab = 看哪位销售的客户
- "全部" tab = 看所有销售的客户

### 搜索

顶部搜索栏：输入客户名字 / 工程单号 / 客户电话 / 身份证 — 实时筛选

### Excel 风格筛选

每一列标题右边都有 ▼ 箭头，点开有：
- **按值筛选**（多选）
- **按条件筛选**（包含/不包含/大于/小于 等）
- **清空筛选**

### 排序

点列标题：升序 / 降序

### 预览报价单

点任意行的"预览"按钮 → 弹出完整的报价单 → 顶部有：
- **导出 PDF** 按钮
- **导出 Excel** 按钮
- **打印** 按钮

### 总金额

底部"汇总"行实时显示：
- 当前筛选后的总单数
- 当前筛选后的总金额
- 当前筛选后的已付定金

## 谁可以用

- 公司财务（开放访问，不需要密码 — 跟报价系统是公司内网概念）
- 公司老板 / 管理层

## 数据从哪来

财务系统**直接读取** Squirrel Designer 报价系统保存在 Google Drive 的报价单（`My Drive / Squirrel Designer / <业务员> / <工程单号>.json`），**不另存一份、不修改原数据**。

销售员在 Squirrel Designer 报价系统新建/修改报价，财务系统**几分钟内自动同步**（刷新页面即可）。

## 出问题怎么办

- **打不开页面** → 联系 Mavis（agent）
- **数据没更新** → 刷新页面（Ctrl+F5 清缓存）
- **某个报价找不到** → 可能是销售员还没保存到云端；去 Squirrel Designer 报价系统里搜下
- **导出 PDF / Excel 失败** → 换个浏览器试试（推荐 Chrome）

## 联系

- 技术问题：Mavis (本仓库的 AI 助手)
- 业务问题：你的销售经理
